## 개발 이유

부모님이 자녀의 컴퓨터를 안전및 보호목적에서 통제하려고 할떄 거의 대부분은 유료로 되어있는 프로그램이 대부분이라 "내가 직접 만들면 어떨까?" 라는 생각에서 만들게 되었다.

## 설계

| 사용언어       | C++언어, Python, HTML, CSS, JS                     |
| ---------- | ---------------------------------------------- |
| 사용라이브러리    | fastapi=0.162.0, pydantic=2.14.3, libcurl(C++언어) |
| 보안에 사용할 기술 | TLS 1.3 + HTTPS                                |

### 역할분리

- C++언어
	컴퓨터에서 실행중인 Ring 3 exe파일을 수집한 이후 부모님의 제어 웹사이트로 보내는 역할.
	부모님 제어 요청에 따라서 특정 프로세스를 중단시키거나 컴퓨터를 끄는 역할.
	특정 시간이 지나면 꺼지는 타이머 역할

- Python
	HTML/CSS/JS의 백엔드 서버
	
	부모님 제어 클라이언트 요청에 따라서 메세지를 받고 C언어 네트워크로 보내는 중간자 역할.
